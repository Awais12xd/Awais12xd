# Scope Creeper Website

Production-ready static marketing website for **Scope Creeper** — a freelancer-focused product that prevents unpaid scope creep by converting extra work into paid change orders.

## Run locally

```bash
npm start
```

Then open `http://localhost:4173`.

## Files

- `index.html` — page structure and content
- `styles.css` — responsive UI and design system
- `script.js` — interactions (mobile menu, calculator, form UX)

## Deploy

This project is static and can be deployed directly to:

- GitHub Pages
- Netlify
- Vercel
- Cloudflare Pages
